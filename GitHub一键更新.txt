裁判文书识别 · GitHub 网页更新
==========================================

在线地址：https://hufelix765-alt.github.io/wenjianshibie/

一、为什么 GitHub 上样式很丑（无颜色、按钮很大）？
--------------------------------------------------
因为 CSS/JS 在 assets 文件夹里，只上传 index.html 时样式加载失败。

现已改为与「发文张」相同：**CSS 和 JS 全部内嵌进 index.html 单文件**。
上传/更新这一个文件即可显示完整美化界面。

二、更新方法
------------
【推荐】双击 GitHub更新.bat

或手动：
  npm run build:pages
  git push origin main

【仅网页上传】
1. 本地运行 npm run build:pages
2. 打开 GitHub 仓库，用本地的 index.html 覆盖仓库里的 index.html
3. Settings → Pages → 点 Save 触发刷新
4. Ctrl+F5 刷新在线地址

三、文件说明
------------
index.html  约 1.5MB，已内联样式和脚本（必需）
assets/     可选，Actions 自动部署时使用
.nojekyll   关闭 Jekyll，避免 README 当首页
