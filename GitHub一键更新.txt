裁判文书识别 · GitHub 网页更新（与发文张相同方式）
==========================================

在线地址：https://hufelix765-alt.github.io/wenjianshibie/

一、为什么打开是 README 文档，而不是上传界面？
----------------------------------------------
GitHub Pages 需要仓库根目录有 index.html（应用首页）。
只有 README.md 时，网站会显示文档，不是应用。

二、本地生成并推送（推荐）
--------------------------
1. 在本文件夹打开终端，执行：
   npm run build:pages
2. 会生成 index.html 和 _next 文件夹（与发文张一样在仓库根目录）
3. 执行：
   git add index.html _next .nojekyll .github
   git commit -m "update: 更新 GitHub Pages 静态站"
   git push
4. 等 1～3 分钟，浏览器打开（强制刷新）：
   https://hufelix765-alt.github.io/wenjianshibie/

三、GitHub 设置（做一次）
-------------------------
仓库 → Settings → Pages → Source 选「GitHub Actions」
（若已是 GitHub Actions，推送后会自动部署）

四、不改代码、只更新网页（与发文张相同）
----------------------------------------
1. 打开 https://github.com/hufelix765-alt/wenjianshibie
2. 本地先运行 npm run build:pages
3. 把 index.html 和 _next 文件夹内容上传到仓库对应位置
4. Commit 后等 1～3 分钟刷新在线地址
